# 实施结果

## 完成状态

本变更已完成统一对话、回复采集、页面扰动控制和提示词库四部分需求。

## 统一对话

- AI 回答初始均为收起状态，点击回答头后才挂载正文。
- 打开详情后仅滚动弹窗内部，并默认定位到最后一轮。
- 桌面端右侧提供按用户原问题生成的轮次导航；窄屏切换为顶部横向导航。
- 新采集记录使用 `react-markdown + remark-gfm + rehype-sanitize` 渲染 GFM。
- 原始 HTML 不执行，远程图片不加载，链接只允许安全协议。
- 旧记录仍按纯文本展示，不把历史普通文本误判为 Markdown。
- 应用过提示词的轮次显示模板名称，并可展开查看当次真实发送内容。

## 回复采集

- 回复定位从高频全页轮询改为 `MutationObserver` 驱动，并保留 1 秒低频兜底检查。
- baseline 保存稳定回答键，采集器只关联提交后新增或变化的回答。
- 回答 DOM 克隆后清理按钮、隐藏节点和工具栏，再同时生成纯文本与 GFM Markdown。
- 流式更新、完成和 partial 均传递两种格式；超时或取消时保留已看到的正文。
- 每个 Provider frame 只允许一个活动采集 lease；下一轮、新会话和 pagehide 会取消旧 lease。
- 采集过程中出现验证码或验证挑战时立即停止并提示人工处理，不自动重试或绕过。

### 千问适配

- 国内页面支持 `.chat-round[data-chat]`、`[data-chat-answers-wrap]`、`.qk-markdown`、`.answer-receiving-card`。
- 兼容 `message-input-textarea`、`response-message-content.phase-answer` 和 `stop-button` 结构。
- 使用 chat ID 作为稳定键，静默完成窗口为 6 秒，站点采集上限为 10 分钟。
- 状态探测 Mutation 合并为 200 ms 防抖，减少流式输出时的重复 DOM 扫描。

## 页面扰动

- 通用发送按钮不再先调用 `focus()`，避免浏览器为聚焦按钮自动滚动页面。
- Kimi 必须聚焦富文本编辑器时继续使用 `focus({ preventScroll: true })`。
- contenteditable 回读会按块元素和 `<br>` 恢复换行，保证多段提示词写入后的逐字符校验。
- 未实现指纹伪装、验证码绕过、模拟可信事件或其他反检测功能。

## 提示词库

- composer 旁新增提示词多选入口，支持搜索、全选、清空和选择状态持久化。
- 管理弹窗支持新增、编辑、删除、上移、下移，名称大小写不敏感去重。
- 提供实际发送内容预览和字符数；选中项在成功发送后继续保留。
- 未选择模板时保持原始问题发送；选择 A、C 时固定生成：

  ```text
  提示词A
  <A 的内容>

  提示词C
  <C 的内容>

  用户
  <问题>
  ```

- 发送前冻结模板快照，所有目标共用同一个 `effectivePrompt`，不改变原有 precheck/stage/commit 原子事务。
- Turn 同时保存用户原问题、模板快照和完整实际发送文本；模板之后被编辑或删除不会改变旧历史。

## 数据兼容

- 协议、响应缓冲、Dexie 记录、JSONL 导入导出和 Markdown transcript 均支持可选 `responseMarkdown`。
- 新增 Turn 和 Exchange 字段均为可选，旧数据库记录无需迁移即可继续读取。
- JSONL 格式继续使用 v3；新字段为同版本可选字段，当前导入器同时接受缺少这些字段的旧文件。

## 验证

- `pnpm check`：通过。
- `pnpm test`：22 个测试文件、110 项测试全量通过。
- `pnpm build`：通过；仅保留现有 workspace chunk 大于 500 kB 的构建警告。
- `pnpm e2e`：18 项通过，覆盖回答默认折叠/展开、桌面/窄屏导航、原子回滚和 A+C 实际输入逐字符一致。
- 真实站点 smoke 未自动执行：需要专用测试账号、明确授权和人工处理登录/验证；mock E2E 不替代真实站点验收。

## 运行边界

- 官网 DOM 仍可能更新；适配失效时应根据有界 diagnostics 和脱敏 fixture 更新 selector。
- 检测到验证挑战后需要用户在官网手动完成，再重新发送。
- 千问网页自动操作和内容采集必须由使用者确认符合其账号、组织授权和服务条款；需要更稳定的长期集成时应优先评估官方 API。
